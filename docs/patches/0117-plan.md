## How it works
- **A fix can ask for more than one press.** `FixCandidate` (`src/lib/trainingCourse.ts`) gained `repeat?: number`, and the qty deviation puts its count on the window fix (`repeat: extra`), where `extra` is how many units too many there are. So "three items where one is enough" carries `repeat: 2`.
- **The graph can too.** `RuntimeSpot` (`src/lib/appGraph.ts`) gained `repeat`, which rides on the action node (`registerActions` accepts `repeat`). routegraph resolves it onto the instruction action (`InstructionAction.repeat`), and `candidateFromStep` reads it back, so a walk with a repeat comes out as one step with a count, not repeated steps.
- **The dock shows it.** `DockView` (`src/state/trainingSession.ts`) gained `repeat`; `TrainingHost` carries it from the chosen candidate; `TrainingDock` draws a small `xN` chip beside the counter. The words are untouched: the qty fix already says "take two out", so this is the count beside them, not a replacement.
- **Tests**: `tests/trainingcourse.test.ts` (the qty window fix carries the count, the plain swipe does not); `tests/appnavgraph.test.ts` (a runtime control's repeat rides on the planned step, not as repeated steps).
