## Design decisions (read these, tell me if one is wrong)
- **One source.** Pages are Markdown files in `help/`. The app and the docs Worker read the same generated `help/help.json`, so they cannot drift. Git history is the version history; the file also carries a content fingerprint (`version`).
- **Three depths in one file.** `## Basic`, `## Deep`, `## Advanced` sections. **Choosing a depth shows it plus the ones above it** (Deep = Basic + Deep). I chose this so nobody reads two copies of a page. Say if you would rather see only the level you picked.
- **Nested and interlinked.** Every page has a `parent` (the folders-in-folders tree) and `[[page-id]]` links; each page also shows "pages that link here". Contents lists are built from `parent`, never written by hand, so a new page appears in the right place automatically.
- **A page cannot be wrong in structure.** The build refuses a set with a dead link, a missing parent, a parent loop, a missing Basic section, an unclosed code block, a stray `##`, or a mermaid block with no diagram type.
- **No new package, no native rebuild.** Everything in this patch is pure TypeScript plus Markdown.
