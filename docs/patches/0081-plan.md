# Patch 0081: a hint visibly arrives (list of 2, point 1)

Stacks on 0080.

## What you asked for
When you request a hint there should be visual feedback that it was given. A toast might be the better place for it. The hint's container (or its text) pulses with colour and size once when a hint (or a new hint) appears, following `const intensity = 48.225 * Math.pow(t, 2) * Math.pow(0.8 - t, 3);` where t is time.

## What was wrong
The hint text showed in two places, and neither reacted when it changed: the bar under the app (the hint text replaced the goal text) and a card that only appeared over windows. Pressing Hint at the last rung changed nothing on screen at all.

## How it works
- `src/lib/hintPulse.ts` (pure, tested): `pulseIntensity(t)` is your curve with t in seconds. It is 0 at t = 0, peaks at t = 0.32 s at about 0.546, and is 0 again at t = 0.8 s. Past 0.8 the expression goes negative, so it is held at 0: a pulse lasts exactly 0.8 s. Size = 1 + 0.15 x intensity (about +8% at the peak). Colour strength = intensity divided by the peak, so it is full strength exactly at the peak. `pulseSamples()` gives the curve as sample points for the native animation (the peak is always a sample; the sampled curve stays within 0.005 of the real one).
- `src/ui/HintPulse.tsx` (`PulseBox`): one time value runs 0 to 0.8 s when `k` changes (and on first appearing). The size, a soft tint and an accent edge are all read off it, so they stay in step. Native driven. Reduce Motion keeps the colour and drops the size.
- `src/ui/HintToast.tsx`: bulb (or flag for the answer), "Hint 2 of 4" or "The answer", the text, a close x, a light haptic and a VoiceOver announcement. Colour is the theme accent (the Hint button's colour).
- The toast shows on every layer (before, only windows had a card). On the main screen it fades after a reading time (6 to 14 s by length) because the bar keeps the text; inside a window it stays until its x is tapped, because the bar is hidden there. Each layer keeps its own "closed" state, so a window shows the current hint when it opens. An off-course notice always takes the place of a hint. The toast uses the existing `Floating` placement, so it moves out of the way of the ringed answer and of the window's Hint and Exit buttons.
- The bar's hint text sits in the same pulsing box (growing from its left edge, so it never spills into the buttons) with a small "Hint 2 of 4" label.
- `useTraining.hintPress` counts every press, including one at the last rung that changes nothing; it is in the view (`DockView.hintPress`), so the pulse fires in the same frame as the new text and again on a press that adds nothing. Pressing Hint now also asks the driver for an immediate check, so the hint appears within a frame or two instead of waiting for the next 120 ms poll.

## Not changed
How many hints a goal has, the ladder rules, the hint count saved in progress (a press at the last rung still counts as one, as before), the Guide (no hints there).
