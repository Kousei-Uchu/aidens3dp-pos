## Correction to the progress doc
The 0019 notes said **Give change but don't track it** records the sale without touching the ledger. The code does not do that: **Done, but don't track it** on the change step still records the notes and coins the customer handed over, and only skips the change given (so the ledger then holds change that has left the drawer). **Exact amount (don't track notes)** does skip both. The cash page describes the real behaviour, and the progress doc line is fixed. I did not change the app. If you would rather the button skipped both, say so and I will make it a small patch.

## Things I noticed while reading the code (not changed here)
- **Gift card codes on receipts (N30).** A sale paid by gift card prints the full code on the receipt made straight after the sale. Only the last four characters are stored on the Shopify order.
- **The split rule is untested.** The next payment amount (`target` in `Pay.tsx`) is written inline in the screen, so the only test is for `allocate` in `tests/lib.test.ts`. Pulling it into a small pure function with tests would be an easy follow-up.
- **Gift card expiry is not checked by the POS.** The sheet shows the date, and Shopify decides at charge time.
- **A cancelled part-paid sale never credits a gift card back.** Already noted in 0031, repeated on the gift card page.
