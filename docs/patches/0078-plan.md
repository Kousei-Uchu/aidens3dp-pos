# Patch 0078: where each fix is taught, and how to do it (list of 5, point 1c)

Stacks on 0077.

## What you asked for
When someone makes a mistake they may not know how to correct it (for example removing items). Each possible correction should name the module that teaches it. When the mistake happens, check whether the person has finished that module and show them how if not. A question mark / help / hint button should show it for people who have finished it, so nobody gets stuck.

## How it works
- `src/lib/trainingRemedies.ts` (pure, tested): `REMEDIES` maps each kind of stray to `{ module, how[] }`.
  | Stray | Taught in | Steps |
  |---|---|---|
  | An item was taken out or reduced (`lost`) | `cart` | tap its tile again |
  | An extra item (`extra`) | `cart` | open the cart, swipe the line left, Remove |
  | Too many (`qty`) | `cart` | tap the line, minus, or swipe and Remove |
  | A discount (`discount`) | `discounts` | line: tap line, Discount, take it off; cart: three dots, Apply cart discount |
  | A price change (`adjust`) | `price-adjust` | line: Item or Line price adjustment, Remove; order: Whole order price, Remove adjustment |
  | A customer (`customer`) | `customer` | small x beside the name |
  | A note (`note`) | `customer` | tap the line, clear the note, Done |
  | Wrong screen / window (`place`, `sheet`) | `welcome` | tabs and Back / Close |
  | A sale went through, a payment started (`sale`, `tender`) | none | Start this part again |
  A module's own `watch` rule can carry `how` and `taughtIn` (default: its own module).
- `diagnose` attaches `how` and `taughtIn` to every deviation.
- The host looks up whether this staff member has finished the teaching module (`isComplete`). Finished: the steps wait behind a "?" button on the card. Not finished (or nothing teaches it): they show at once with "This is taught in <module>".
- **Hint while the card is showing now opens the steps** (before, it spent a hint nobody could see, because the card hides the hint text).
- A module that is not built yet still has a planned title, so the card can name it.
