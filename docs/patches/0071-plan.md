# Patch 0071: smoother page transitions (Training corrections, 1 of 7)

Stacks on 0070. This starts the new list of seven Training corrections (smoother transitions, animated Guide, off-course handling in the Checks, themed highlight, smoother stage and step changes, hint feedback, virtual terminal). They are numbered 0071 to 0077, one patch each, in that order.

## What you asked for
- Smoother transitions on most pages.

## Cause
Only the page that arrived was animated (0067). The page it replaced was removed in the same frame, so every change was a cut followed by a slide. Starting and ending practice swapped the whole screen in one frame as well, and inside a course the cart and Pay pages had no transition at all.

## Fix
- **The old page leaves as the new one arrives** (`src/ui/RouteTransition.tsx`). Going forward the old page drifts a little to the left under the new one. Going back, the page you are leaving slides off to the right over the one revealed. Pages fade as they move, with a fast-then-slow curve in and a gentle-then-quick curve out. The slide distance scales with the window (`slideDistance`).
- **Worked out in render, not in an effect**, so the arriving page knows it is entering on its first frame (no one-frame flash). The tab screen stays drawn underneath while a page slides over it or away from it.
- **Direction is right even at the same depth.** Training list to a course is forward, a course back to the list is back (`transitionDir`, `ROUTE_RANK`).
- **Pages a running course allows (the cart, Pay) animate while practice is on.** When the course ends they go back to being ordinary pages, and a practice-only page is never kept drawn after the practice data has gone.
- **A dip to the page colour** (`src/ui/Veil.tsx`, `dipThrough`) when practice starts (the course page becomes the real till), when you leave from the bar, and when a stage finishes and returns you to the course page. The screen fades to the page colour, the change happens unseen, then it fades up. The "cannot start yet" message is shown before the dip, not after it.
- **Reduce Motion** still turns all of this off. Every page outside Training is drawn exactly as before (it is now inside a plain full-size wrapper, which looks the same).

## Tests
- `tests/motion.test.ts`: slide distance limits, where the leaving page goes forward and back, which layer is on top, direction by depth then by Training page order, which routes animate (with and without a running course), and the timings.
