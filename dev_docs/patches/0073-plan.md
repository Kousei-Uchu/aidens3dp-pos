## What you asked for
- Smoother transitions on most pages.

## Where 0071 stopped
0071 made Training pages (and the cart and Pay while a course runs) slide, and said the rest was "one line". Everything else still cut: pages, tabs and the guided checkout's steps.

## Fix
1. **Every pushed page slides in** (`isAnimatedRoute` is now true for any named page). Forward arrives from the right, back from the left, anything else rises. Unchanged: Reduce Motion turns it off.
2. **The old page leaves too, only where that is safe** (`canLeaveDrawn`, `LEAVE_DRAWN` in `src/lib/motion.ts`). The leaving page is drawn again as a fresh copy, so it has to look right from stored data alone. Lists and read-only screens (Saved carts, Orders, Items, Customers, Reports, Gift cards, Drawer, Settings, Staff, Diagnostics, Help, Training, the cart) leave smoothly. **Pay, Create item and Edit item never do**: Pay depends on a sale in flight and the item forms on unsaved text, so redrawing them would flash blank or wrong content. They simply give way to the page that arrives, which still slides in.
3. **Tabs fade and rise** when you switch (`Enter` keyed by tab for Inventory, Transactions, Notifications and More; `TabPane` for Checkout). Checkout is not remounted, so the cart and scanner state survive exactly as before; `TabPane` only replays the animation when the tab becomes active.
4. **Guided checkout steps fade and rise** (Customer, Discount, Review, Pay each wrapped in `Enter`; the item picker uses `TabPane` because it stays mounted so the grid keeps its place).
