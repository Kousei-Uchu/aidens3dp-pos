## What you asked (T8)
> I'd like to have a pop out nested side-menu for navigation (like how the web docs have) as well as the current method

## How it works
- A **Contents** button (list icon) in the Help header opens a panel that slides in from the left over the page (260 ms, none with Reduce Motion), with the whole page tree: Help home first, then each section with its pages nested under it.
- A section's arrow opens or closes it (the page does not change). A title opens that page and closes the menu. Tapping outside or the X closes it with no change.
- Opening the menu opens every section above the page you are on and highlights it, so you can see where you are.
- Search, the trail chips, the topic cards, the lists, links, Back and Help home are untouched: this is an extra way round, as asked.
- Pure logic in `src/lib/helpTree.ts` (`treeRows`, `openFor`, `toggled`), safe against a broken or looping tree; panel in `src/ui/HelpMenu.tsx`.
- Not done: the docs website already has its own sidebar (0054/0058), so only the app changed. Not a permanent sidebar on wide iPads, since you asked for pop-out; say if you want that too.
