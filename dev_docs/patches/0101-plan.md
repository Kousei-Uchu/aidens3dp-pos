# 0101: Training, Find the right item fixes, part 2 of 3

Reported: Find items #4 (offscreen), #5 (brand orange); General #1 (item windows treated the same).

## Causes
- #4: `spot()` treated an off screen target as missing, so there was no scroll guidance, and with no ring the whole screen dimmed and blocked touches.
- #5: patch 0080 made the ring follow the theme accent (peach, near white).
- General #1: `line.minus` and `line.remove` were one id each for every line window.

## Changes
- `scrollNeed` and `scrollSay` (`trainingGeometry.ts`); `DockView.scroll`; the host records the need of the last spot measured; `ScrollCue` in the overlay; the dim is dropped while the target is wholly off screen.
- `BRAND_ORANGE` (`trainingPalette.ts`) used for ring, pointer, glow and bar. Light dim alpha 0.6 to 0.72 so the orange keeps 3:1 contrast.
- `lineMinusSpot(key)`, `lineRemoveSpot(key)`, `lineKeyOf`; `SnapLine.lineId`; `LineEditor` publishes which line is open (`setOpenLine`) for later use; the course's window candidates use the line's own buttons.
