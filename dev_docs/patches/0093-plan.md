## How it works
- **Course `sign-in`** (`src/training/modules/sign-in.ts`), six minutes: Info (names and roles, PIN or pass, stepping away, roles), Show (nine steps, including a pass that fails and the PIN fallback), Guide (nine steps on the real practice till), Check 1 (switch by pass, lock, sign in by PIN) and Check 2 (a cancelled pass so the PIN is the only way in, and a switch while a sale is in the cart).
- **Practice staff.** A course can set `practiceStaff`. The practice till then has two people with known credentials, Casey (cashier, PIN 1234) and Morgan (manager, PIN 2468, plus a cashier pass), requires sign-in and starts signed in as Casey. They are built with the same PIN hash and pass hash as real staff, so the real sign-in code runs unchanged. They exist only in the sandbox.
- **Practice pass.** A camera cannot scan a pass that is not real, so while training is on the Scan pass window draws the pass with a **Scan this pass** button (`src/ui/PracticePass.tsx`). A `pass` injection swaps in a cancelled pass, which the till refuses exactly as it refuses a real cancelled one.
- **Injections.** `staff` (start as Casey, as Morgan, or on the Sign in screen) and `pass`. A `staff` injection only acts when practice staff exist, so a course without them can never lock the real till. The checker refuses either injection on a course without `practiceStaff`.
- **What a step can test.** The snapshot now carries who is signed in and whether the Sign in screen is up.
- **Spots.** PIN pad (any digit), Unlock, Scan pass, Lock register, and the practice pass button. The practice grid gains the Switch staff and Lock POS tiles.
- **Progress fix.** The signed-in person can be Casey or Morgan during practice, so a finished course and the "taught in" check now use the real person, held in the swap snapshot (`realStaffId()`).
- Not done: a wrong PIN as a Check 2 failure (it cannot be forced to happen), so it is explained in the Guide and Show instead. The Help button on the Sign in screen is not available in practice (Help is not one of the course's pages).
