## What changed
- **Pages slide.** Opening Training, a course, or going back now slides the page in (from the right going forward, from the left going back) while fading, instead of cutting. `RouteMotion` in `App.tsx` does this for the routes listed in `TRANSITION_ROUTES` (`training`, `trainingRun`) only.
- **The hub builds up.** The intro text, the count and each course card come in one after another (`stagger`, capped so a long list never makes anyone wait).
- **The practice intro card** (the page before Guide, Check 1 and Check 2) rises in.
- **The dock** at the bottom of Guide and Check slides up when practice starts, and the spotlight layer fades in rather than appearing.
- **Reduce Motion.** If the iPad's Reduce Motion setting is on, all of this is skipped and things just appear.
- New: `src/lib/motion.ts` (pure helpers) with `tests/motion.test.ts`, and `src/ui/Motion.tsx` (`Enter`, `useReduceMotion`).

## Not changed
- Leaving a page is still instant: the page being left disappears as the new one slides in. A true cross-over would mean keeping the old page mounted, which the navigation does not do today. Say if you want that.
