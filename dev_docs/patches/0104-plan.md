# 0104: Training, the rest of the fallbacks

Finishes the list left open in 0102 and 0103.

## Changes
- `Step.recoverFrom` and the host: tried after `target` and before `recover`, first one on screen wins; `validateModule` checks the spots.
- sign-in g-pass-open, g-pass-scan, g-lock, g-pin; find-items g-search; pay-card g-tap.
- pay-card g-receipt now finishes on "sale done and the Receipt window closed", so a swiped-away window cannot strand the step. Its target is still No receipt.

## Left as is
Guide steps whose target is always on screen where the step runs (the intro and info steps, g-total, g-terminal, g-wait) need no fallback. Typed-text strays outside the find items typing steps are still not covered.
