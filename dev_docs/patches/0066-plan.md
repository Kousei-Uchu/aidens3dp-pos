# Patch 0066: Info in the same animated style as Show (correction 1 of 8)

This is the first of eight patches that answer your list of Training corrections. They stack in order: 0066 to 0073, each on top of the one before and on top of the current repo (which already has 0065).

## What you asked for
- The Info stage should have the same animated, graphical style as Show.

## What changed
- `info` is now the same `Demo` format as `show`. One engine (`src/lib/trainingDemo.ts`) and one renderer (`src/ui/DemoView.tsx`) draw both, so every fix to Show from here on (the next patches) applies to Info too.
- Info keeps its own job: it explains what the task is, when you need it and roughly how it works, using diagrams and cards (not mock screens): a course card appears, the six parts build up as chips and icons, the practice-data tag, the Hint button, and the green tick. The camera moves in on each, a note with an arrow names it, and you step with Next, Back and Replay. Nothing moves on by itself.
- The old actor-and-beat scene is gone: `src/ui/SceneView.tsx` and `src/lib/trainingScene.ts` are deleted, along with their test.
- The checker now holds Info to the same rules as Show (3 or more steps, ids, items that fit, icons that exist), and a new test makes sure every course Info actually changes as it goes and directs the eye.
- The chip node can now be green (`tone: 'good'`), used for the finishing tick.
- Writer's guide, DEV_NOTES item 6 (one sentence added to Info), the Training help page, next-steps and the progress doc updated.
