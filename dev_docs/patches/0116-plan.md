## The problem
The comment in `src/app.navgraph` claimed per-line copies were registered at runtime, but they were not. Every one of a cart line's controls (`line.minus:<key>`, `line.note:<key>`, `line.discount:<key>`, and the rest) hung off the one shared `tab_checkout` screen, so a walk could not name the exact window a fix was in. The shared `sheet_line` screen and its sub sheets existed but nothing mapped to them.

## How it works
- **The template is keyed.** `src/app.navgraph` declares `VAR ITEM_KEY : string` and the `sheet_line` opening edges fill it in (`cart.line:$ITEM_KEY$`). The plan's `sheet_line` screen is now the template.
- **One copy per open line.** `ensureLineWindow` in `src/lib/appGraph.ts` registers `sheet_line:<key>` from the template with `params: { ITEM_KEY: key }`, so the copy's opening step points at that exact cart line (`cart.line:<key>`). routegraph resolves `$ITEM_KEY$` inside the action data (verified).
- **Line controls live there.** `screenOfSpot` (`src/lib/appControls.ts`) now returns `lineWindowScreen(key)` (`sheet_line:<key>`) for the line-window prefixes, and the three sub sheets (discount, item price, line price) fold into the line window. `registerRuntimeSpots` puts the line's window on the graph before registering its controls there.
- **The person's node follows the open window.** `stateNode` returns `sheet_line:<key>` when a line window is open (there is a window on the graph), so a fix inside it is not told to close it, and a fix outside it is walked out through it (`sheet_line -> tab_checkout`, a new edge).
- **The walk says what it is doing.** The opening edges carry `say="Open the item's window first."`. `edgeMeta` now reads live edges, so a copied edge keeps its words (the old one-time index only knew file edges).
- **Tests** (`tests/appnavgraph.test.ts`, +2, 29 total): a line's window is its own node and a walk to a line control names the exact window and points at that cart line; a fix inside the open window adds no close step, and one outside closes it and walks out through Done.
