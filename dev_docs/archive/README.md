# Archived docs

One-off reports and generated files kept for the record. Nothing here is a live source: the current plans and lists are
one level up in `dev_docs/`, and the running log is `dev_docs/PROGRESS.md`. A file moves here when the work it describes
is finished and nothing reads it any more, but its findings are still worth being able to look up.

| `F2-SWEEP.md` | The sweep of the app for screens that lead nowhere, settings that do nothing and dead ends (F2, 2026-10-18). |
| `TRAINING_MODULE_BUGS.md` | Training module bugs collected by hand before the routegraph work (0113 to 0118). Written before that change and not re-tested since, so treat the entries as history, not as a live list. |

| `DEVICE_TEST_GUIDE.html` | The generated click-through test guide (F7, 2026-10-18), 512 steps across 71 sections. Its source is `dev_docs/DEVICE_TESTS.md`, which is the file to edit. |
