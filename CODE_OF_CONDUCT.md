# Code of conduct

This is a one-person repo with a public read-only audience. The short version:

- Be decent. Disagree with the code however you like; the people are not up for grabs.
- No harassment, bigoted language, or dogpiling.
- Issues here are not a support channel and will not become one. If you file one anyway and it is rude, it will be closed.
- Pull requests that introduce AI-generated slop (untested, unreviewed, padded with boilerplate) will be closed without reading.

That's the whole policy. There is no committee, no reporting form, and no appeal process.
